--------------------------------------------------------------------------------
ANDROID (TERMUX) QUICKSTART:
--------------------------------------------------------------------------------
1. Extract zip:
     unzip "2d-video-editing-studio.zip" -d 2d-video-editing-studio
     cd 2d-video-editing-studio
2. Run setup:
     sh setup_mobile.sh
3. Run video generation (with fast preset):
     python3 studio.py autopilot --voice anuj --lang hi --fast
4. Preview on phone:
     termux-open master.mp4

--------------------------------------------------------------------------------
DESKTOP CLI WORKFLOW:
--------------------------------------------------------------------------------
1. Create project:
     python studio.py new ~/videos/my_video && cd ~/videos/my_video
2. Voiceover:
     CARTESIA_API_KEY=... python studio.py voice --voice anuj --lang hi
3. Plan & Prompts:
     python studio.py plan && python studio.py prompts
4. Generate Flow assets & key:
     python studio.py generate --mode agent && python studio.py key
5. QA check & sheet:
     python studio.py check && python studio.py sheet
6. Render:
     python studio.py render --fast
