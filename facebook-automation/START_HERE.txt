====================================================================
  FACEBOOK AUTOMATION & SEO STUDIO — QUICK START GUIDE
====================================================================

Welcome to the Facebook Automation & SEO Studio plugin for Antigravity.
This plugin enables 100% autonomous Facebook posting, scheduling, re-editing,
deleting, and viral SEO generation on Mobile (Android / Kiwi Browser) and Desktop.

--------------------------------------------------------------------
1. ONE-COMMAND SETUP (MOBILE & DESKTOP)
--------------------------------------------------------------------
Run the setup script from your terminal:
   ./setup_mobile.sh

This automatically installs required dependencies (python, websockets, pillow, mcp)
and links the skills into your Antigravity environment.

--------------------------------------------------------------------
2. EXTENSION INSTALLATION (KIWI BROWSER / CHROME)
--------------------------------------------------------------------
1. Open Chrome or Kiwi Browser (on Android phone).
2. Go to: chrome://extensions
3. Enable "Developer mode" toggle.
4. Click "Load unpacked" and select the 'extension' directory:
   [path_to_plugin]/extension
5. Open facebook.com and ensure your account is logged in.

--------------------------------------------------------------------
3. LAUNCHING THE MCP SERVER
--------------------------------------------------------------------
Run:
   python3 mcp_server/server.py

The WebSocket bridge opens on ws://127.0.0.1:8766.
The extension connects automatically with zero configuration.

--------------------------------------------------------------------
4. AVAILABLE MCP TOOLS
--------------------------------------------------------------------
- fb_status        : Check bridge connection & queue health
- fb_login_status : Detect active Facebook profile/page dynamically
- fb_publish      : Publish post (text/photo/video/reel) with DOM verification
- fb_schedule     : Schedule post for future publication
- fb_edit_post    : Re-edit an existing post caption
- fb_delete_post  : Delete or move a post to trash
- fb_list_posts   : View recent posts & status history
- fb_seo_generate : Generate viral Facebook copy, hook, bullets, hashtags
- fb_comments     : Post first comment (resource link) or reply
- fb_doctor       : Run environment self-check & diagnosis

--------------------------------------------------------------------
5. GUARANTEES
--------------------------------------------------------------------
✓ ZERO DUPLICATES: SHA-256 media hashing + normalized caption check.
✓ PRIVACY CLEAN: Zero hardcoded IDs or accounts. Auto-detects dynamically.
✓ REACH PROTECTION: External links placed in first comment to protect organic reach.
